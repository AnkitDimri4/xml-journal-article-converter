Building an XML Journal Article Converter as an Intern Project

Ankit Dimri – Full‑Stack Developer • Dehradun, India

Abstract

This project implements an XML Journal Article Converter in Python that parses simple journal‑style HTML into a JATS‑inspired XML structure. The tool extracts the article title, authors, abstract, sections, and references and outputs a clean, machine‑readable XML file suitable for journal editorial and QA workflows.

Introduction

Many journals rely on XML, especially JATS, to ensure their articles are searchable, reusable, and machine‑readable. For this internship project, I built a small but realistic converter that transforms author‑submitted HTML into a structured XML article tree aligned with JATS‑style tagging (<article>, <front>, <body>, <back>, sections, and reference list).

Methods

The converter is written in Python using the lxml library. It parses the source HTML and identifies the main heading as the article title, the first paragraph as the author line, a dedicated abstract paragraph, and subsequent headings and paragraphs as sections. A "References" heading marks the start of the reference list, which is emitted as a <ref-list> element in the back section.

These elements are mapped into an XML tree with explicit <front> (title, authors, abstract), <body> (section structure), and <back> (references) nodes. The final output is a well‑formed, pretty‑printed XML file that can be inspected manually or integrated into automated QA checks.

Results

The current version exposes a simple command‑line interface: python convert.py input.html output.xml. This makes it easy to test locally and to plug into scripts or CI pipelines for bulk conversion or regression tests. The codebase is modular, with separate components for HTML parsing and XML construction, so it can be extended to support DOCX input or richer JATS tagging if required.
